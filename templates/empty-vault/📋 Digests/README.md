# Digests

`cycles/` is the historical Thursday cycle archive. Thursday auto-run is stopped. `workflow_dispatch` on `weekly-digest.yml` is emergency only. This template does not add sample cycle files.

`cluster/` is the weekday 归堆 path: `📋 Digests/cluster/YYYY-MM-DD.md` (multi-day `YYYY-MM-DD_DD.md`). 想法梳理 writes it. A Cloud Agent pushes the private vault. This template does not write those notes, and information-flow Actions do not own that push.

`📋 Digests/daily/` is not created here. Historical daily files stay where they already are. takeaway 已 offline，本 PR 不另挂停排程。This template does not delete `scripts/daily_takeaway.py`.

# Inbox

Source files land here, one subdirectory per source.

Writers: you, and a portable sync for a source you connect.
Non-writers: creating this vault does not fetch sources and does not run an index.

`_index/` is reserved for a machine index. It starts empty. A first index run is optional and is not part of creating this vault.

Subdirectories: `YouTube-Likes`, `Snipd`, `WeRead`, `X-Bookmarks`, `Instagram-Saves`, `manual`.

Tokens and passwords do not belong in this tree. OAuth and sync setup live in the information-flow package, outside this vault.

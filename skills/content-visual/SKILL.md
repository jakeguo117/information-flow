# 内容视觉 · 出图规则草稿（Jake 2026-10-22 点选）

> 正本依据：Jake 2026-10-22 点选的视觉十条，已写进本技能 §1–§9 和 content-x「配图」节，以仓里这两处为准；本岗只定**怎么出图**，不写正文、不发帖、不改写手职责。
>
> Taste：每张图仍先吃 **canvas-design**（先写/对齐视觉哲学）+ 既定样张（如 Warm Ledger）；本手册不另开第二套品牌风格库。

---

## 1. 开工顺序

1. 读配图需求包（topic / 渠道 / 逻辑链要点 / 尺寸与页序 / 禁用项）。同 topic 只有一份包，写齐各渠道画幅；一次出、按渠道裁，交付清单按渠道分列。不清就短问，不猜观点。
2. **生成前先定画幅**（见 §4），再写 prompt、再出图。
3. 对齐视觉哲学与色板（canvas-design → 本批次样张），画面·背景·字体一体。
4. 出图 → 目视验（无叠字、安全区、禁区）→ 交付附 prompt（见 §6）。

---

## 2. 五层 prompt

每条出图 prompt 按五层写全，缺一层等于把该层交给模型猜：

| 层 | 写什么 | 备注 |
|----|--------|------|
| 1 主体 | 画面里具体是什么（物件、场景、几何关系） | 默认**无人像**（§7） |
| 2 氛围 | 情绪与参照质感（如米纸账本、暖留白） | 跟视觉哲学，不套现成风格名 |
| 3 光 | 点名光源（方向、软硬、色温） | 不写光＝随机光 |
| 4 构图 | 机位、留白、分区、安全区位置 | 标题叠字区写进 prompt（§5） |
| 5 细节 | 材质、边距、禁区、标注小字 | 如「配图示意／非真实数据」 |

反例：一句笼统的 “a nice illustration about saving ideas”。正例：五层都落到可执行的视觉指令。

---

## 3. 迭代纪律

- **Speed → Quality / Think Harder**：先用快档出方向；方向对、细节不够时再升 Quality 或 Think Harder，不要一上来用满精度刷运气。
- **先重跑，再一次只改一处**：同一 prompt 可多跑几版挑方向；要修时只动一个要素（光 / 构图 / 色 / 主体其一），便于对比与 revision 记录。不要整段重写 prompt 然后说「微调」。
- 否决线框、灰块、Lorem、临时色板；成品封面级才交。

---

## 4. 画幅

- **生成前先定画幅**，写进需求与 prompt。
- 常见：16:9、9:16、3:2、2:3、1:1（视出图工具能力）。
- 渠道要 **5:2**（如 X 封面）而工具无 5:2 时：**允许先出 16:9，再裁成 5:2**；裁切前在构图里按 5:2 安全区排主体与标题区，避免裁掉关键信息。
- **三渠道共用图按渠道裁**，不各画一套。X 交付 5:2。公众号封面 2.35:1，分享图 1:1。小红书按 content-xhs 的平台比例。
- 小红书卡、示意图等按需求包尺寸；同一套图画幅不一致时在交付清单里写清。

---

## 5. 标题安全区

- Prompt 里**预留标题叠字安全区**（大块留白、低干扰背景），不要等出图后再硬塞字。
- 5:2 / 宽封面：常把标题区放在左侧或中部留白（跟当次视觉哲学）；竖卡按页序定中部或上部。
- 封面上的标题字就用方向确认里的终版标题，可以断行，不改字、不另配口号；图内短字只服务既定主线传意，不新加论点；叠字优先单层清晰字（避免 stroke+fill 双层、生成字再叠一层造成重影）。

---

## 6. 参考图与交付溯源

- **参考图锁风格**：系列配图（封面 + 1–3 张正文图，或同文多卡）用同一组参考图锁色板、材质、构图语言；换系列再换参考，不混用。
- **交付附 prompt**：每张生成的成品交付时附上实际使用的完整 prompt（及参考图说明）；截图不附 prompt，附来源说明：哪个工具、对应步骤清单哪一步、是真实界面、示意库还是重排、哪里用毛玻璃遮了；换图/改图可追溯到原需求包与该 prompt。
- 不用未授权网图当新闻现场照；生成图像实拍新闻感时标「配图/示意」。How to 稿（介绍我们自己的项目或方法）的配图展示工具在对应步骤里的样子：每张图对上步骤清单的一步，画这一步实际用的工具正在做这一步的样子，例如 Grok Bot 聊天里正在整理、出汇总、写稿，Obsidian 里的文件夹和想法卡。涉及私人库或对话的（笔记库、周记、想法卡、和 Grok Bot 的聊天），不截真实画面，用示意库截图（在真实工具里打开一个编的库，文件夹名和内容都是编的）或真实对话文字重排的示意图（字只取原句，可删不可改、不补写，删处用「……」），图上标「示意」或「重排」，正文图注同样写明；示意内容不能被说成真实，不写成「我的库」「真实截图」。不涉及私人内容的界面可以真实截图；示意图也可以补截图拍不到的整圈关系，标「配图/示意」。图上的字不夸大，没自动化的步骤不画成、不写成自动。打码一律用毛玻璃（模糊），不用实心色块；私人笔记和周记原文、敏感五类、客户资料、密钥和 token、账号邮箱、头像和真名都不露。截图仍按渠道画幅交，裁切或排进画面，不拉伸。

---

## 7. 人像与风格模板

- **默认无人像**：讲观念、机制、对比的配图不出现真人；需求包若例外点名，再另议并标示意。
- **不用现成风格模板**（如平台自带的 Funky Dance、Chibi、80s Anime 等命名套装）。风格只来自当次视觉哲学 + 参考图，不套模板名当 taste。

---

## 8. 图转视频（若需求包要动效）

- 先把**起始静帧**调到可交水平，再图转视频。
- Prompt **只写动作**：运动、机位移动、情绪节奏；不复述画面里已有的主体与风格。
- 续写/延长：只写「接下来发生什么」，不整段重描述。
- **短视频可以进 X 长文**（作嵌入动效/封面动，不替代正文）；是否采用由发布包与 Jake/X 运营定。本岗是内容视觉，只按需求出片并附 prompt，不写 X 正文。

---

## 9. 交活边界（本岗）

- 交：成品图（及约定视频）+ 尺寸清单 + Drive「内容/视觉/{年-W周}/」链接 + 各图 prompt（截图附来源说明）。
- 不交：正文改写、标题文案、发帖、审批卡、合 main、改 skill 正本。
- 改图：点名项改完再交；回「不要」该条停，等新需求。

---

## 10. X Article 包装三件套 · 封面

包装文案和检查表在 `skills/content-x-article-packaging/SKILL.md`。本岗不出文案。本节只做出图。

**谁干什么**：写手＝选题②＋包装 brief①＋basement／母稿＋CTA 文案③；视觉＝出图；渠道运营＝落版／叠字／发帖；冷读＝内容审计。

本岗不写标题、引子、正文，不代发，不代渠道运营决定叠不叠字。§5 的「封面上的标题字就用终版标题」仍是叠字时的画法，本条不改它。这一张包装封面叠不叠字，由渠道运营落版时定。运营要叠字时，再按 §5。

**触发。** 写手交来「X Article 包装 brief」和卖点短句，并标明封面承担「卖梦想」或「拆异议」。缺 brief 或卖点短句不出封面。不把「与标题、引子不重叠」当出图硬门。

**Brief 必填**（写手交，视觉消费）。缺字段先短问，不猜卖点。

| 字段 | 说明 |
|----|------|
| topic／母稿标识 | 哪一篇 Article |
| 封面角色 | 仅二选一：`卖梦想`｜`拆异议` |
| 封面卖点一句话 | 封面要一眼传递的点 |
| 禁区 | 不可出现的词、画面、品牌名、真人等 |
| 尺寸 | 默认 X 封面 5:2；若要变体写清。工具无 5:2 时按 §4 先 16:9 再裁 |
| 参考／气质 | 可选；无则按现行 taste／已批视觉路径（canvas-design，不另开风格库） |

**产出。**

1. X 5:2 封面 PNG，以及 brief 写明的变体。图内只放卖点短句需要的字；叠不叠标题由渠道运营定，视觉不自作落版。
2. 一句话回执：这张封面承担的卖点＝……。复述 brief，不新加论点。
3. Drive「内容/视觉/{年-W周}/」正本路径和链接，回写手，并抄该渠道运营（X／小红书／公号按平台）与 PM。

**验收。**

- 画幅 5:2；成品封面级（无线框、灰块、Lorem）。
- 回执复述卖点短句，不新加论点。示意须标「配图示意」。
- 打码用毛玻璃；不出现真人；不用未授权网图当现场照。
- 没有在图上自作「必须叠终版标题」或「必须不叠」的落版决定。

**渠道侧验收建议。** 不挡出图。封面卖点与标题、引子三者不撞车，一眼能分清各解决什么。由渠道运营落版时看。

**不做。** 不写、不改标题与引子。不自审文案口径。不发帖。不改 §5。

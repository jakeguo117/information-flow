# content-x-process-topic

流程长文选题。未成名或要立专业感时，优先写 **process articles**：让读者体验「你怎么想／怎么做」，不是观点清单堆砌。

**谁加载**：内容写手。组合选题原料仍走 Ideas；本 skill 只做「能否做成流程文」的滤镜，通过后才进采访／骨架。X 长文底稿／母稿仍由写手在 Jake 认可后经 content-x 写。X 运营不再写母稿。

**谁干什么**：写手＝选题②＋包装 brief①＋basement／母稿＋CTA 文案③；视觉＝出图；渠道运营＝落版／叠字／发帖；冷读＝内容审计。

**来源**（机制对照，非硬 KPI）：https://x.com/i/article/2100174331804540928 ；镜像 https://haowenji.com/articles/x-2100174331804540928 ；帖 https://x.com/ItsMeBenChan/status/2114698558712774840 。纸面内容侧草案同目录。作者宣称倍率不当选题验收数字。

## 触发

- 账号未成名／要立专业感，需要 X 长文选题。
- 本周要定长文选题（含复活计划里「先定一篇流程长文」的内容侧部分）。

## 输入

- Ideas 组合选题原料（现行 A+B+C／A+B／单独 A 等已认可组合）。
- 可点名的**已验证资产**候选：winning tweet／热帖、client result／案例、internal SOP、lead magnet、已确认 Idea `expression` 里的可核验经历。
- 不输入：无来源的「想写的观点」、Journal 原句、未确认 suggested_expression、运营侧排期表。

## 做什么

1. **只扩已验证资产**（原文口径：winning tweet／lead magnet／client result／internal SOP → 长文；**很少从零硬写**）。
   - 每条候选写清：资产是什么、可核验指针（链接／日期／Idea id／内部文档名）、读者能「跟做或跟想」的哪一段过程。
2. **流程文滤镜**（相对「组合选题原料」）：
   - 组合原料仍从 Ideas 来，本 skill **不另起平行选题流**。
   - 过本滤镜才进采访／骨架 F1–F7：问「读者看完能否复述你怎么想／怎么做？」——不能 → 换资产或退回补料，不硬开写。
3. **过程骨架**（选题卡上写，不是正文目录）：
   - 读者将经历的步骤／判断节点（3–7 步为宜）：处境 → 你怎么判断 → 你怎么做 → 边界／反例（有材料才写，不编）。
   - 禁止：纯观点排列、无第一手或可标明出处的外部案例、为凑步骤编经历。
4. **与包装／正文的衔接**：
   - 选题卡通过后，再进 `content-x-article-packaging`（可在正文前）与 content-core 方向卡／content-x 正文。
   - 本 skill 不写正文、不定封面成图。
5. **检查表**：
   - [ ] 来源资产可核验，非从零硬写
   - [ ] 读者可复述的过程骨架已写在卡上
   - [ ] 非纯观点堆砌
   - [ ] 未把 Journal 原话或未确认句当资产
   - [ ] 未把作者宣称倍率当「本题必达 KPI」

## 产出

- **选题卡**：来源资产（指针＋一句为何已验证）＋读者可复述的过程骨架＋拟中心思想一句（须落在已确认 expression 范围内，或标「待方向确认」）。
- 交接：交采访／骨架 → 再 basement；不交运营代发。

## 验收

- 读者（或冷读）看完卡上过程骨架，能复述「你怎么想／怎么做」。
- 有可核验资产指针；无「无资产从零硬写」选题进骨架。
- 未用宣称倍率当硬指标。

## 边界／不做

- 不代发；发帖归 X 运营。
- 不写小红书／公众号；不写运营 ④⑤ 细则。
- 封面出图归视觉；本岗选题卡可不附 brief（包装 skill 另做）。
- 不发明 Jake 未确认观点；禁靠 context 才懂的词。
- 敏感五类／禁 Journal 原话：与 content-core 对齐，不复述全文。
- 不另起与 Ideas 组合流平行的第二套选题台账。
- 不编造 Article 未核验的逐步 playbook；只标来源链接与纸面／镜像已写机制。

## 与邻 skill 关系

- **须先或可并行**加载 `content-core`。
- 正文另循 `content-x`；本 skill 只到选题卡。
- 加载顺序：选题②（本 skill）→ 采访／骨架 → Jake 认可 → `content-x-article-packaging` → content-x 正文 → `content-x-cta-loop`。
- 一次一类或写清顺序；可与 content-x 同任务链。

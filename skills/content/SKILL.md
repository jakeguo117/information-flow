# content（已停用）

不要用本技能写帖。旧的「一个 content 技能出三版」已废止。

同 topic 仍一次交齐 X、小红书、公众号，但三版分别按平台技能写。缺任一版不得交审批卡。

1. 先加载 `skills/content-core/SKILL.md`
2. 出封面、配图或卡片之前，加载并遵守 `skills/canvas-design/SKILL.md`
3. X：`skills/content-x/SKILL.md`
4. 小红书：`skills/content-xhs/SKILL.md`
5. 公众号：`skills/content-wechat/SKILL.md`

canvas-design 不是第四个内容主技能。平台技能只补画幅和中文回退。

「周记原话直接引用」已废止。敏感、逻辑链、图源、不代发和发布包路径见 content-core。

字段、指纹和批准形状仍见 `references/content-record.md`（`content-0.1`）。自检清单以 content-core 为准。

# content（已停用）

不要用本技能写帖。旧的「一个 content 技能出三版」已废止。

任务只要写 X、X Article、X 长文或 X 短帖：由 X 运营加载。加载顺序是 content-core →（出图才）canvas-design → content-x。禁止同一写作上下文 Skill load content-xhs 或 content-wechat。只交 X。一次交齐三版不适用于这种任务。内容写手不写这一轮。

整周多渠道发布包，或他明确要三版交齐：同 topic 一次交齐 X、小红书、公众号，三版分别按平台技能写。X 版由 X 运营加载 content-x。小红书和公众号由内容写手加载 content-xhs、content-wechat。缺任一版不得交审批卡。

1. 先加载 `skills/content-core/SKILL.md`
2. 出封面、配图或卡片之前，加载并遵守 `skills/canvas-design/SKILL.md`。X 配图由内容视觉按 content-visual。
3. 只要 X：X 运营只加载 `skills/content-x/SKILL.md`。到此停止，不加载下面两步。
4. 小红书：内容写手加载 `skills/content-xhs/SKILL.md`（小红书自己的任务，或整周包 / 三版交齐）
5. 公众号：内容写手加载 `skills/content-wechat/SKILL.md`（公众号自己的任务，或整周包 / 三版交齐）

运营五条由 X 运营加载 content-x-ops。写长文和跑运营可以分线程，一次只做一类。编辑审稿仍是编辑（非作者），不写死 bot。

canvas-design 不是第四个内容主技能。平台技能只补画幅和中文回退。

「周记原话直接引用」已废止。敏感、逻辑链、图源、不代发和发布包路径见 content-core。

字段、指纹和批准形状仍见 `references/content-record.md`（`content-0.1`）。自检清单以 content-core 为准。只要 X 时，不按「三版都要有」去加载 content-xhs 或 content-wechat。

## 强制 Humanizer 硬门

没有检查表不算成稿。下次照 main 写一篇，走到这一步不靠口头补。

| 落点 | 原文摘录 |
|---|---|
| `skills/editor/SKILL.md` 第 45 行、第 56 行 | 检查对象是标题、小标题和全部段落，不含文件头和出处。依据就是 humanizer-zh 全清单。没有这张表，不算成稿。 |
| `skills/editor/SKILL.md` 第 168 行 | 没有这张表，不算成稿，下面的查不算数，也不交冷读。 |
| `skills/content-x/SKILL.md` 第 16 行 | 成稿前必须按 editor「必加载 humanizer-zh」逐条跑完全清单，写出检查表，盖住标题、小标题和全部段落。 |
| `skills/content-x/SKILL.md` 第 32–34 行 | 正文写完、交冷读之前，必须加载 humanizer-zh，按 editor 逐条跑完。没有这张表，不算成稿。 |
| `skills/content-x/SKILL.md` 第 80 行 | 成稿前必须有 Humanizer 检查表。没有检查表不算成稿。 |

检查表格式：每条「通过」或「已改（原句→新句）」；命中但保留的写理由；文末写查了多少项、改了几处、保留几处。文件放稿子旁边，不进仓。不把某一篇的检查表抄进 skill。

# 模板：原话是骨头，写作者长肉 对照表（每篇必填）

> 空模板。每篇 X 长文母稿、每升一版，都从这里复制一份重填，旧表不沿用。填好的表存成 `X母稿-vN-骨头长肉对照表.txt`，放在稿子旁边，不进本仓。没有这张表，不算成稿，不交冷读。规则以 `skills/editor/SKILL.md`「原话是骨头，写作者长肉」为准；和 skill 冲突时，以 skill 为准。这张表按原话一条一行，查每块骨头上长了什么肉；逐段标「原话／事实／展开」的对照表照旧另做。

## 文件头

- 稿件：`X母稿-{topic}-vN-YYYYMMDD.txt`

- 核心洞察（稿头那一句）：
- 采访记录和事实核查的文件名：
- 日期（香港时间）：

## 填法

- 「原话（骨头）」：抄 Jake 或受访者的原话，带采访行号。观点、经历、感受只能从这一栏来。
- 「写作者展开（长肉）」：抄正文里展开这块骨头的句子，带段号。没展开写「无」，再说明为什么不用展开。
- 「展开做法」：只填 editor 允许的七种之一：机制、类比、外部证据（附链接，已核）、读者场景（「你可能也……」）、把信念推一层、把他的例子讲透、写成步骤。
- 「是否保留原话意思」：填「是」或「否」。「否」必须改稿，不能交。展开里出现他没说过的经历、对话、当时的想法，一律算「否」。
- 结尾 punchline 单独占一行，「原话」栏写它对应的原话行号。

## 自查

- [ ] 每一节都有四层：观点 → 为什么 → 例子或证据 → 对读者意味着什么。观点那一层在上表「原话」栏里找得到。
- [ ] 原话和展开大致各占一半。展开明显少，回去补「为什么」和「对读者意味着什么」。
- [ ] 任何一段展开删掉，前后原话仍连得上。
- [ ] 「是否保留原话意思」没有一行是「否」。
- [ ] punchline 的意思能指回上表的原话行号。

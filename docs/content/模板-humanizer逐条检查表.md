# 模板：Humanizer-zh 逐条检查表（每篇必填）

> 空模板。每篇 X 长文母稿、每升一版，都从这里复制一份重填，旧表不沿用。填好的表存成 `X母稿-vN-humanizer检查表.txt`，放在稿子旁边，不进本仓。没有这张表，不算成稿，不交冷读。做法以 `skills/editor/SKILL.md`「必加载 humanizer-zh」为准；条目含义以 `skills/humanizer-zh/SKILL.md` 正文为准，本模板只列条目名，不复述模式。和 skill 冲突时，以 skill 为准。

## 文件头

- 稿件：`X母稿-{topic}-vN-YYYYMMDD.txt`
- 稿件 sha256：
- humanizer-zh commit（抄 `skills/humanizer-zh/SOURCE.md`）：
- 检查对象：标题、小标题和全部段落，不含文件头和出处
- 日期（香港时间）：

## 填法

- 每一行都要填，不能只抽查破折号、粗体、「而是」。
- 「本篇命中原句」：没命中写「无」；命中就抄原句，带段号（段号同对照表）。
- 「改后」：改了写新句；命中但保留，写「保留：」加理由；没命中留空。
- 「通过」：填「通过」「已改」或「保留」。
- 「三问审计」按第五组防过度纠偏六条做，不另发明三问。

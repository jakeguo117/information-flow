# 范文与反面例：store-iterate

> 写 X 长文母稿时，动笔前读一遍范文，自评前对一遍反面例。只学结构、长肉和结尾，不抄句子，也不把这篇的事实、数字、外部引用搬进新稿。和 `skills/editor/SKILL.md`、`skills/content-x/SKILL.md` 冲突时，以 skill 为准。

## 范文

`docs/content/范文/store-iterate-v4.txt`：store-iterate 第四版母稿全文，按原文件逐字入库（sha256 `80ddd67dfc3b3cabf531d2c381149af83b10908fd5cd5e6ce53b846736cb5d4d`）。文件头和出处里提到的采访记录、事实核查、对照表、检查表、v1–v4 稿件都是当时放在稿子旁边的过程文件，不在本仓。

读的时候看这几处：

- 稿头先写「核心洞察」和「结尾 punchline」，全文每一节都指回那一句（editor W12）。
- 每节都有四层：他的原话给观点，写作者补机制、外部研究、读者场景、今晚可做的几步（editor「原话是骨头，写作者长肉」）。
- 小标题顺序按读者要先懂什么排，不按采访题号排。
- 最后三段回扣开头那个问题，最后一句是 punchline，出处写明对应哪几行原话；没有求互动。

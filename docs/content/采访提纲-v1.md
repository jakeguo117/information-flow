## 必问问题（对应骨架四栏）

顺序建议：开场场景 → 中心 → 分论点（每条绑证据）→ 补读者顾虑 → 收尾。可随他回答跳序，但**四栏都要勾上**。

### 0｜破冰（宽口，1 题）

- 「这周这几个 idea 里，哪一块你最近自己真碰到过？随便讲一分钟。」
  - 目的：漏斗顶部，找真实场景与他自己的话（出处 E；对接清单 #2 开场场景）。

### 1｜开场场景（骨架栏：开场）

必问：
1. 「读者打开第一眼，该看见你生活里的哪一幕？（不是口号，是你真干过／真卡住的一刻。）」
2. 「那一幕里，你当时在干什么、看见了什么、哪一点让你决定要写？」

追问（不够具体时）：
- 「再具体一点：在哪个界面／哪份文件／哪次聊天？」
- 「如果只能留一句当时的心里话，是哪句？」

填满标准（本栏）：有**可复述的一幕**（谁／在哪／看见什么），且能自然接到中心；不是「读完你会…」式预告（清单 #2/#3；方案「开场」）。

### 2｜中心一句（骨架栏：中心）

必问：
1. 「用一句大白话：你这篇到底想说什么？（像跟朋友说，不要术语。）」
2. 「为什么是这个，不是旁边那个 idea？」
3. 「读完的人应该能复述哪一句？你先说一遍给我听。」

追问：
- 「这句话里哪个词可以删掉还不伤意思？」
- 「如果有人听成别的意思（比如听成教程／听成吐槽），你最怕被听成哪种？那我们怎么改说法躲开？」
- 他用了绕词时：「这句话换成你跟助理说话会怎么说？」（出处 D）

填满标准（本栏）：**恰好一句**主张；Jake 能口头复述；大白话；一篇只有这一个中心（清单 #5/#3；备核闸门）。

### 3｜分论点（骨架栏：分论点；通常 2–3 条）

必问（对每一条重复一轮）：
1. 「为了把中心说圆，你要分几步讲？每步用一句为什么／怎么做说完。」
2. 「这一步如果删掉，中心会塌在哪？」
3. 「这一步下面，读者看得见的证据是什么？（文件名、真实计数、改前改后、你亲口做过的事——不是把中心换个说法。）」

追问（每条）：
- 「举一个你自己的例子，越具体越好。」（出处 E；清单 #6）
- 「这个数字／文件名我去哪核对？核对不了就换一条。」（清单 #7）
- 「有没有人会反驳这一步？你怎么答？没有就别硬编。」（清单 #8）
- 「这一步是在推中心前进，还是在复述中心？」（清单 #5）

填满标准（本栏）：每条分论点＝**一句推进**＋**至少一条可核验证据**；条数通常 2–3；没有「空主张节」（清单 #5/#6/#7；方案「分论点／证据」）。

### 4｜证据总检（骨架栏：证据；可与 §3 合并问）

必问：
1. 「把你刚才提到的证据列一遍：哪条对应哪个分论点？」
2. 「哪一条其实只是感觉、还没有东西可指？要补还是砍掉这个分论点？」

追问：
- 「日记／周记原话能不能进稿？」（默认不能，清单 #19——若他想引用，改成他此刻重说的话，不贴原文。）
- 「有没有收益类百分比／夸张承诺？」（默认砍，清单 #4/#18。）

填满标准（本栏）：每个分论点下证据可指认；无发明数字；敏感／日记原话为零。

### 5｜读者顾虑（可选但推荐；撑清单 #8）

必问：
1. 「熟人听完会甩一句什么反对？你怎么接？」
2. 「没有真实反对就说没有——我们不凑。」

填满标准：有则写透；无则标明「本篇无强反方」，不编。

### 6｜标题／首屏口吻（写前对齐，仍属骨架讨论）

必问：
1. 「标题你希望读者以为这是在说什么？用你的话说五个字到十五个字。」
2. 「有没有听起来很厉害、但没你自己味道的说法？那些不要。」（出处 D）

填满标准：标题方向好懂＋有他味道；不锁死最终标题文案（可写时再打磨，但方向他点过头）。

### 7｜收尾（每次采访固定）

1. 「还有什么我该问但没问到的？」
2. 「这四栏（开场／中心／分论点＋证据）你哪一栏还不满意？现在改。」
3. 「骨架这样，你是否认可可以开写？」（必须得到明确「行／认可」类答复；含糊＝未过闸门。）

## 追问法（怎么用，不是题库）

| 手法 | 怎么做 | 出处 |
|---|---|---|
| 漏斗 | 先宽口故事 → 收窄到一句主张 → 再收窄到证据细节 | E：NN/g Funnel |
| 问题梯子 | 标出本场必带走 3 答（通常：中心一句、开场一幕、每分论点各一条证据）；其余可弃 | E：Craft of Reporting |
| 回声 | 用他刚说的词追问：「你说的『××』是指什么？」 | E：crumbs／follow-up |
| 举例 | 「举个你这周真实发生的」；不要抽象定义 | E；清单 #6 |
| 核对 | 「这句话我写进稿里，读者能去哪验证？」 | 清单 #7 |
| 纠偏 | 他滑向教程／黑话／金句时，拉回：「直接说为什么／换成大白话」 | 出处 D；卡#8 |
| 静默 | 答太短时停 3 秒，让他补一句 | E：Craft of Reporting |
| 不诱导 | 不把你预写的中心念给他点头；中心必须他先说 | 方案「禁止黑箱」；Jake 18:19 |

禁止的问法：
- 「你是不是想说〔你替他总结的中心〕？」→ 诱导。
- 「要不要写成闭环／认知复利／信息输入？」→ 塞术语（D）。
- 一次抛三个问题 → 拆开问。

## 什么算「骨架填满」（硬闸门自检）

对照好文章清单 #20 ＋ 方案 ④。下面 **全部勾上** 才算填满；缺一不算。

| # | 勾选条件 |
|---|---|
| F1 | **中心**：恰好一句大白话主张；Jake 能复述；不是两个中心拧在一起 |
| F2 | **开场**：有一幕真实场景（可复述），能自然接到中心；不是预告式开头 |
| F3 | **分论点**：2–3 条；每条是推进，不是复述中心 |
| F4 | **证据**：每条分论点下 ≥1 条可指认证据（文件／计数／改前改后／亲历）；无发明数字 |
| F5 | **顾虑**：有真实反方则写透；无则标明不编 |
| F6 | **用语**：骨架笔记里无他已否的绕词／没头没尾金句；标题方向不「假威严」 |
| F7 | **认可**：Jake 明确说可开写（「行／就这样写／认可」）；「再想想」＝未过 |

填满 ≠ 可以发帖。填满＋认可 → 才写 X 长文母稿 → 再走冷读／硬门／草稿（流程以当时 skill／职责为准；Eng/HRBP 改完后执行）。

**未过闸门时**：只准继续采访或改骨架笔记；**禁止**生成 X 长文正文（含提纲式正文）。出处：备核「骨架闸门」；清单 #20；方案.html ④。
